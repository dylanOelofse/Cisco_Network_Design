# Office Network Design 

## 📌 Overview  
This repository contains:  
**A complete office network design** using **CISCO Packet Tracer**.
   
The goal is to provide a **cost-effective network setup** for employees in the office and remote locations.  

---

## Description
Designed a network with multilayer switches, VLANs, DHCP pools, and inter-VLAN routing. Configured DNS, TCP/IP, and static IPs for critical devices. Enabled internet access and web server connectivity.
The **CISCO Packet Tracer** file simulates the **complete network design** for deployment.
